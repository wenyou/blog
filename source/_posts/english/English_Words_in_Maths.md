* Discrete Mathematics 离散数学
> discrete  /dɪˈskriːt/   adj.分离的，各别的
> mathematics  /ˌmæθəˈmætɪks/   n.数学；数学运算
> * **What is Discrete Mathematics?**
>> 对比：**微积分（高数 / 复变）研究连续的东西**：实数、光滑曲线、连续变化，时间无限细分。 
>> **离散数学研究 “一块一块、分开、可数” 的东西**：整数、集合、真假命题、图、树、有限状态。 
>> 微积分研究“连续变化”，离散数学研究“一个一个的东西及它们之间的关系”。
>> 核心：离散 = 不连续，一份一份分开
>>
>> 离散数学主要四块内容: 数理逻辑、集合论、图论、组合数学。 额外还有：布尔代数、数论、有限自动机。
>> 高等数学（连续）：研究**变化**，求导积分，处理连续运动。  
>> 离散数学：研究**结构、关系、计数、逻辑**，处理分开的个体。
>> 计算机的数学根基，计算机存储全部是 0 和 1（离散），没有真正连续, 计算机 = 离散世界，离散数学 → 数据结构 → 算法 → 计算机理论。 写算法、数据库、网络、密码学、AI 逻辑、编译器全部离不开离散数学。
>> 超短总结： 微积分：世界是光滑连续的。  离散数学：世界是一个个独立小块，研究小块之间的逻辑、关系、数量。
>
> **可以把离散数学理解成：研究一个一个、一个一个“数得清”的东西，以及它们之间关系的数学。**
> “连续数学” vs “离散数学” 
> 比如一条直线： 
>> ────●────────●────────●────→
>>    1.2      2.5      3.8
>
> 直线上可以有无限多个点，1 和 2 之间还有 1.1、1.01、1.001……
> 这种“连续变化”是微积分等数学主要研究的东西。
>
> 而离散数学更像： 
>> ●   ●   ●   ●   ●
>> A   B   C   D   E
>
> 东西是一个一个分开的。
> 例如：
>> ・ 1、2、3、4…… → 一个一个的整数
>> ・ 一群人 → 一个人一个人
>> ・ 一张地图 → 一个城市一个城市
>> ・ 一个网络 → 一个节点一个节点
>> ・ 一台电脑 → 0 或 1
>> ・ 一道逻辑题 → 真 / 假
>
> 这些都是离散的。
>
> * **离散数学最重要的几个部分：**
>> 可以把它想成计算机科学背后的“数学工具箱”。
> **① 逻辑**
> 研究：什么是真的？什么是假的？
> 计算机的 if / else，本质上就和逻辑有关。
>
> **② 集合**
> 研究： 一堆东西放在一起，怎么描述？
>	 A = {1,2,3,4,5}  就是一个集合。
> 集合是离散数学非常基础的东西。
> 
> **③ 图论**
> 研究： 东西之间怎么连接？
> 例如：
>>        北京
>>      /      \
>>    上海     西安
>>      \      /
>>        广州
> 
> 城市是节点，道路是边。
> 这就是一个“图”。
> 于是可以研究： 两个城市之间最短路线、哪个城市最重要、网络哪里容易断、怎么设计最省钱的网络
> 
> **④ 排列与组合**
> 研究：有多少种可能？
> 例如：
> 	3个人： 小明、小红、小刚
> 排队有多少种方法？
> 	3!= 6
> 这就是组合数学的基本问题。
> 密码学、概率、人工智能中都会大量用到。
> 
> **⑤ 递归**
> 研究： 一个问题如何由更小的同类问题组成？
> 例如：
>	1,1,2,3,5,8,13,...
> 后面的数字等于前两个数字相加。
> 这就是著名的斐波那契数列。
> 计算机算法里大量使用递归思想。
>
> **⑥ 算法**
> 研究：解决一个问题，到底需要多少步骤？
>
> **用一个例子彻底理解**
> 假设你要设计一个微信式社交网络：
>>	小明 ─── 小红
>>   │        │
>>   │        │
>>	小刚 ─── 小丽	
> 
> 离散数学会问：
> 	集合：
>		有哪些用户？
>		V={小明,小红,小刚,小丽}
>	图论：
>		谁和谁是好友？
>		E={(小明,小红),(小明,小刚),...}
>	逻辑：
>		小明是否可以看到小红的朋友圈？
>	组合：
>		4个人一共有多少种好友关系？
>	算法：
>		怎样找到“朋友的朋友”？
>	最短路径：
>		小明认识小丽，中间最少需要经过几个人？
>
>	你会发现：
>		这就是一个真实的互联网问题，但背后全是离散数学。
>
>
>

* Manhattan Distance 曼哈顿距离
> Manhattan /mənˈhætən/ ；  Distance /ˈdɪstəns/  n.远处；疏远，隔阂；（人或物之间的）差别，差距；进展；距离；  v.疏远，远离；  adj.远距离的；
> 定义: 
> 二维平面两点 P₁(x₁,y₁)，P₂(x₂,y₂)
> $d_{manhattan}$ = |x₁ - x₂| + |y₁ - y₂|
> 只能沿横竖网格移动，不能斜着走，像在城市街区走路，所以叫曼哈顿距离。
